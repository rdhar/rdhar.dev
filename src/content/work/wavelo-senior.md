- Wrote reusable Terraform modules that apply the same infrastructure policies across every AWS environment. The GitOps workflows built on them removed the need for a HashiCorp Enterprise licence.
- Ran hands-on GitHub Actions workshops and knowledge shares across teams; more than 15 engineers now use loosely coupled CI/CD pipelines for their day-to-day automation.
- Designed a multi-account AWS landing zone with VPC peering, federated IAM roles and least-privilege access. New environments now take hours instead of weeks.
- Compared ECS Fargate with EKS on performance, cost and features for production workloads. Kubernetes suited the hybrid deployments better, so I moved Vault secrets and Nomad jobs to Helm charts.
- Set up Amazon MSK with ACLs for event-driven services, bridging legacy systems with low-impact migrations that kept upstream and downstream data consistent.
- Set observability standards with Grafana, Prometheus and OpenTelemetry, and built DORA metric dashboards for deployment frequency and lead time.
